## 2. ISA Transactions 2026：**CfC 用在真实车辆上**（本批第二重要）

- **题录**：Xu Y, Wei C, Hu J. *Hybrid vehicle state estimation using closed-form liquid neural networks and nonlinear Kalman filtering.* **ISA Transactions** 176:658–670, **Sept 2026**. DOI **10.1016/j.isatra.2026.06.027**。（作者单位：北京理工大学 + 南洋理工大学；通讯作者 Chao Wei）
- **摘要（来源：BIT Pure 机构库公开页，2026-10-04 取用；与 Semantic Scholar 返回一致）**：
  > 车辆动态状态（尤其**侧偏角**）难以用车上传感器直接测量，复杂工况与显著传感器噪声下更难。本文提出**把 CfC 网络与增强无迹卡尔曼滤波（UKF）结合**的混合估计框架：CfC 网络处理**序贯 IMU 与 GPS 测量**，给出初步状态预测**及对应不确定度**；这些预测作为**伪量测**进入基于模型的 UKF，不确定度用于构造**量测协方差**。进一步，利用 CfC 模型内在的**多步预测特性**设计**数据驱动的 sigma 点采样策略**，更准确地近似局部观测分布。框架先在 **KITTI 数据集**与 **Carsim 生成数据**上验证，随后在**测试平台上开展实车实验**。结果表明该混合框架能同时应对未知噪声，并在精度与鲁棒性上优于基于学习与基于模型的基线。
  > **代码已开源：`https://github.com/HITXCI/w-state`**
- **对 P1 的用处**：
  1. **这是"CfC 在一辆真实车上跑通并有实车实验"的 2024+ 证据** —— 与 Chahine（四旋翼）、RA-L 2022（Pi Zero 无人机）互补，把"CfC 能上真实移动平台"从空中扩到地面车辆。**P1 论证控制器选型时，这是最新的可引先例。**
  2. **它给出了一个 CfC 与模型融合的范式**：CfC 输出当作**伪量测 + 不确定度**喂给 UKF。→ **P1 的"LNN + MPC 混合"（AGENTS.md §6 架构原则"大胆决策，小心修正"）可以引用它作为"学习模块 + 模型模块如何接口"的已发表模板**（虽然它接的是 UKF 不是 MPC）。
  3. **代码开源** → D3 可给 2。
- **注意（不要越界）**：它的任务是**状态估计**，不是控制；**没有任何控制器、没有编队、没有弦稳定性**。P1 **不得**用它支撑任何控制性能主张。
- **缺什么**：`[未取得全文]` → 无法核：实车平台是什么车、传感器配置、**推理频率与算力平台**（是否 MCU）、参数量、有没有 CI/多种子。→ **P1 若要用它支撑"可实时"，必须先拿到这四项。**

## 3. Robotics 2024：**CfC 当控制器**（机器人域）

- **题录**：Urrea C, Garcia-Garcia Y, Kern J. *Closed-Form Continuous-Time Neural Networks for Sliding Mode Control with Neural Gravity Compensation.* **Robotics** 13(9):126, 2024. DOI **10.3390/robotics13090126**。（Unpaywall：**VoR-OA，CC-BY**；本机被 MDPI 边缘节点 `Access Denied` 403 拦截，未取得全文）
- **摘要（来源：OpenAlex，2026-10-04）**：提出基于滑模控制（SMC）结构的鲁棒控制器 **SMC-CfC-G**，为 **UR5 工业机器人**建立**逆模型**，并用前馈 MLP 神经网络做**重力补偿**（优于传统建模得到的重力向量）。**引入 CfC 网络来构建机器人逆模型**，实现高效建模。在末端执行器承受**负载与力矩扰动**下验证，表现出对扰动与工况变化的鲁棒性。
- **对 P1 的用处**：**"CfC 被用作闭环控制器的一部分（逆模型）"的直接先例**，且是工业机器人这种真实系统。→ P1 的"CfC 做控制器"不再是 CfC 原文里那个"图像→转向曲率的模仿学习序列模型"（CfC 原文并**不是**控制器，见 `notes/cfc-nmi2022.md`），**本篇补上了"CfC 可以是控制器组件"的旁证**。
- **注意**：机器人域、SMC 结构、**无编队无交通**；且它用的是**逆模型 + 重力补偿**，与 P1 的"势场条件化连续控制"机理不同。**只能作旁证，不能作对标。**
- **缺什么**：`[未取得全文]` → 参数量、推理频率、硬件平台、有无 CI/多种子，全部未知。

## 4. T-ITS 2024：混合网联条件下的**超车可行性**（与 OTF 最近的 T-ITS 工作）

- **题录**：Zhao L, Qian H, Hawbani A, Al-Dubai AY, et al. (n=7). *Overtaking Feasibility Prediction for Mixed Connected and Connectionless Vehicles.* **IEEE T-ITS** 25(10):15065–15080, 2024. DOI **10.1109/TITS.2024.3398602**。被引 37。
- **摘要（来源：OpenAlex，2026-10-04）**：V2X 渗透率逐步提升，路上将长期存在**装了 OBU 与没装 OBU 的混行**，通信能力不对等。本文提出**针对装有 OBU 车辆的换道超车可行性分析与预测方法**，给出**非二值的换道超车可行性指标**与**相应速度引导**，辅助车辆完成超车。
- **对 P1 的用处**：
  1. **与 OTF 的定义域（超车）直接重合**，且是 T-ITS（P1 的目标 venue 之一）→ **必引的相关工作**。
  2. 它给出**"超车可行性指标 + 速度引导"**这一输出形式，可作为 P1 描述 OTF 输出（分级/连续值）**同期的对照口径**。
  3. 它的"连通/非连通混行"与 P1 的"人工/自动混行"是**不同的异质性维度** → P1 需在 Related Work 里说清二者的差别，避免被审稿人认为重复。
- **取得路径**：green OA 接受稿在 Napier 机构库（<https://napier-repository.worktribe.com/file/3636737/1/>，本机 403）；正式版在 IEEE Xplore（机构订阅）。
- **缺什么**：`[未取得全文]` → 可行性指标的定义式、数据来源（仿真还是实测）、样本量、有无统计。
