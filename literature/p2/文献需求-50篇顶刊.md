## 红队检查（≥3 条致命质疑 + 消解所需证据；项目纪律强制）

> 视角分工：① 领域内最懂的人（世界模型 / 驾驶生成）② 方法与统计审稿人 ③ 主编 / 邻域读者。
> **本节的用途是限定这张图能支撑什么，不是给它背书。**

### 质疑 1（领域）：这张图里可能已经有"以交互/社会场为条件"的世界模型，P2 的新颖性会被打掉
本图的"社会交互与压力场建模"节（8 篇）与"驾驶世界模型"节（8 篇）各自都存在，
**但本次入选的 50 条里，没有一条题名同时含"压力场/社会力"与"世界模型/条件生成"**。
这只说明**题名层面**没有命中，**不能**证明不存在——相关工作的题名常写
"interaction-aware world model"、"multi-agent scene generation" 而不用 "social field"。
- **消解所需证据**：对入选 50 条的"驾驶世界模型""多智能体交通流""条件模态"三节（共 18 篇）
  **逐篇精读其条件模态定义**，确认是否已有以交互场/社会力为条件的先例；若有一篇，
  P2 的定位句必须从"首个"降级为"首个以**可解释标量**（OTF）为条件的……"。
- **代价**：这是 P2 定位成立与否的**关键路径**，不可跳过。

### 质疑 2（方法与统计）：文献图不能替代"空缺存在性"的证明，而 P2 的 Introduction 需要后者
本图是**每式前 60 条的相关度抽样**（候选池 412 → 入选 50），**不是系统综述**。
以抽样结果断言"尚无 X"在方法上不成立（选择性偏倚 + 截断偏倚）。
- **消解所需证据**：① 针对"OTF/社会压力场 + 世界模型"做一次**定向检索**（不是宽检索），
  记录检索式、命中数与逐条判定；② 用 `research-gap-hunter` 的四道闸门做新颖性核验；
  ③ 在稿件里把空缺陈述写成"据我们在 [通道, 日期] 的检索未发现"而非"不存在"。
- **本项目现状**：**尚未执行**，属待办。

### 质疑 3（主编/邻域）：50 条里有若干 venue 层级偏低或主题贴合的"补充性证据"，会稀释可信度
入选规则含 venue 加权（顶刊 3.0 / 权威 2.0 / 其他 1.2）与每节最低条数保障（4 条），
后者会把"为了凑满该节"的低分条目放进图里（本次"条件模态与可控 rollout"仅 3 条即为例证：
该节满足双层过滤的条目本就稀少）。若不标注，读者会把它们与顶刊条目等量齐观。
- **消解所需证据**：生成该图时保留每条的分项得分与其在候选池中的排名（本次已保存在
  `shortlist.jsonl`），撰稿时**只把 venue 层级达标且方法直接可比的条目用作对标**，
  其余仅作背景引用；并在稿件 Related Work 里显式区分"对标工作"与"背景工作"。
- **代价**：低，但必须做，否则会重演"引用一堆弱相关工作"的常见问题。
