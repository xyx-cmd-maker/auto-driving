# 种子独立性自检：判定逻辑（规格，非实现）

> 状态：**规格**。实现属 W2（见 `README.md` §5）。本文件只写"判什么、怎么判、什么算通过"，不写代码。
> 背景：`configs/seeds/seedset_s1.yaml` 声明了 `independence` 字段，`configs/schema/results.schema.json` 把 `notes.seed_independence` 列为必填。
> **为什么需要它**：`seeds` 列表有 ≥5 个种子，**不等于** 5 次独立重复。若 5 个种子共用同一份数据划分、只有初始化不同，有效样本量仍是 1（`discipline-rigor` §0.2/§0.3）。这个自检就是拦这件事。

对应脚本（待实现）：`scripts/smoke/check_seed_independence.py`
对应产物（待生成）：`runs/smoke/seed_independence_<seedset>.json`

## 1. 输入与前置条件

| 输入 | 要求 | 缺失时的行为 |
|---|---|---|
| 种子集配置 | `configs/seeds/seedset_s1.yaml`（含 `independence` 块） | 退出码 2，报"配置不完整"，**不得**用默认值代替 |
| 结果文件 | 至少一个 `results/<paper>/*.json`，且 `mode: "real"` | 退出码 2；对 `mode: "smoke"` 的文件一律拒绝 |
| **划分清单** | 每个种子对应的**折内实体集合**（见 §2 的 `partition manifest`） | 退出码 2，报"缺少划分清单"——**这是最容易缺的输入** |
| 特征时间戳（可选） | 每条样本的时间戳与所用 OTF 窗的左右端点 | 缺此项则 CHECK-4 记为 `not-run`，不得记为 `pass` |

**判定原则**：输入不全 → 拒绝出结论（退出码 2），**不允许"证据不足但默认通过"**。

## 2. 必须存在的中间产物：划分清单（partition manifest）

自检无法从结果 JSON 反推划分，因此要求每次运行产出一份划分清单，字段如下：

| 字段 | 含义 |
|---|---|
| `seed` | 种子 |
| `fold` | 折编号（train / val / test） |
| `entity_group` | 实体粒度的取值（vehicle / drive-run / scene 的具体 ID） |
| `n_samples` | 该折该实体的样本数 |
| `partition_hash` | 该种子下**整体划分**的哈希（用于 CHECK-1 快速比对） |

清单放在 `runs/real/<experiment>_<seedset>_partition.json`；没有它，`verified` 只能为 `false`。

## 3. 四项检查（判定逻辑）

### CHECK-1　划分是否真的随种子变化（**红队指出的核心项**）

这是本自检存在的首要理由，也是"格式填了"与"实际独立"的分界线。

- **判据**：计算各种子划分的差异度。对每对种子 (i, j)，取训练折实体集合 A_i、A_j（|A_i| = |A_j| = k，实体池大小 N），算 Jaccard 相似度 J = |A_i ∩ A_j| / |A_i ∪ A_j|。
- **阈值不是拍脑袋定的，而是从零分布算出**（见 §4）：
  - **参照系（零假设）**：两个种子各自**独立随机**抽 k 个实体时，J 的分布。J 的期望随 N 减小而**升高**（小实体池里随机划分本来就长得像），所以固定阈值 0.90 会失效——这就是必须算零分布的原因。
  - **判 fail**：所有 `partition_hash` 完全相同（种子只影响初始化、不影响划分）。
  - **判 fail**：平均 J > 零分布的 95 分位 J₉₅（**比随机划分还要像**，说明划分几乎没变）。
  - **判 pass**：平均 J ≤ J₅₀（比随机划分更不像），且 `partition_hash` 不完全相同。
  - **判 warn**：J₅₀ < 平均 J ≤ J₉₅（仍在随机范围内，但偏保守）→ 允许 `verified: true`，但报告必须写明"划分差异处于随机范围内、接近下界"，并在稿件措辞上保守一档。
  - **判 degenerate（小池退化）**：若 2k > N，任何两次抽样的并集都等于整个实体池，J 恒为定值、CHECK-1 **无法通过**判定区分 → 不得置 `verified: true`，转 §5 的替代路线。
- **报告必须写出**：每对种子的 J 值、最小值、最大值、均值，**以及 N、k、由它们算出的 J₅₀ 与 J₉₅**。只给"通过/不通过"不够，因为审稿人会问阈值从哪来。

### CHECK-2　实体是否跨折泄漏

- **判据**：对每个种子，训练折实体集合 ∩ 测试折实体集合 = ∅。
- **通过**：交集为空（对**所有**种子成立）。
- **不通过**：存在任一实体同时出现在 train 与 test → **fail**，并列出泄漏实体 ID 与样本数。
- **边界情形**：若实体总数极少（例如只有 3–5 个 drive-run），完全分离会同时废掉测试集 → 此时**不允许**用"放宽 CHECK-2"解决，应改走 §5 的分层模型路线。

### CHECK-3　预处理是否先于划分

- **判据**：标准化/归一化的统计量（均值、方差）、特征选择结果，是否只由**训练折**算出。
- **可判定方式**：检查管线配置中这些步骤的声明位置与 `split_policy` 的先后顺序；若无法从配置判定 → 记 `not-run`，**不得**记 `pass`。
- **不通过**：统计量用全量数据算出 → **fail**（典型数据泄漏）。

### CHECK-4　OTF 窗是否含未来信息

- **判据**：对每个样本，滑动窗右端点时刻 t_right 与决策时刻 t_decide 的关系必须满足 t_right ≤ t_decide。
- **为什么单列**：OTF 是**窗内已发生**的超越事件计数。若窗右端点越过决策时刻，标签泄漏成立；若窗必须完全落在过去，则 P1 需要额外报告"OTF 可用信息边界"（对 Δt = t_decide − t_right 的敏感性），否则 OTF 对当前决策的信息量可能为零。
- **通过**：所有样本满足 t_right ≤ t_decide，且报告 Δt 的分布（min / median / max）。
- **不通过**：存在 t_right > t_decide → **fail**，列出违规样本数与最大越界量。

## 4. 阈值：由随机划分的零分布算出（不再用固定值）

### 4.1 为什么不能用固定阈值

固定阈值（如 0.90）会在两端同时失效：

- **实体池小**（如 N = 12、每折 k = 8）：两次**独立随机**抽取的 Jaccard 期望本来就有 0.5 以上，0.90 几乎永不触发，检查形同虚设；
- **实体池大**（如 N = 5000、k = 4000）：随机划分之间的 Jaccard 期望就很低，0.90 又过于宽松。

因此阈值必须**随 (N, k) 计算**。

### 4.2 零分布的算法（实现时按此写）

零假设 H₀ 的语义：**两个种子的划分都是各自独立、均匀随机地从 N 个实体中取 k 个**。在这个假设下：

- 交集 |A ∩ B| 服从超几何分布：P(X = x) = C(k, x) · C(N − k, k − x) / C(N, k)；
- 并集 |A ∪ B| = 2k − X；
- J = X / (2k − X)。

**实现方式（二选一，优先前者）**

| 方式 | 做法 | 适用 |
|---|---|---|
| 精确解 | 对 x 从 max(0, 2k − N) 到 k 求和 PMF，得到 J 的分布，取 50 分位 J₅₀ 与 95 分位 J₉₅ | N ≤ 2000 时（组合数可精确计算） |
| 蒙特卡洛 | 用**固定随机种子**（写进配置，如 `null_seed: 20260101`）重复 M ≥ 10000 次独立抽取，取经验分位数 | N > 2000 时；固定种子保证阈值可复现，不因重跑而漂移 |

**必须写进报告的三个量**：`N`（实体池大小）、`k`（每折实体数）、`null_jaccard: {j50, j95, method, seed?, M?}`。
若各种子折叠大小不一致，按**最小 k** 计算（取最保守的零分布）。

### 4.3 其余参数

| 参数 | 取值 | 说明 |
|---|---|---|
| 最少实体数 | 10（每个折） | 低于此值走 §5 替代路线 |
| 最少种子数 | 5 | 与 `AGENTS.md` §4 一致 |
| 蒙特卡洛次数 M | ≥ 10000 | 仅在走蒙特卡洛时生效 |

**这些是工程约定，不是统计定理**；报告里必须写明取值来源（本节算法）与调整历史。**阈值写进配置，不硬编码。**

### 4.4 零分布实测值（写实现时的自检基准）

按 §4.2 的超几何算法实算，H₀（两个划分各自独立均匀随机抽 k 个实体）下 J 的分位数：

| N（实体池） | k（每折） | J₅₀ | J₉₅ | 最小 J | 支撑点数 | 是否退化（2k > N） |
|---|---|---|---|---|---|---|
| 12 | 6 | 0.333 | 0.500 | 0.000 | 7 | 否 |
| 20 | 10 | 0.333 | 0.538 | 0.000 | 11 | 否 |
| 50 | 25 | 0.316 | 0.429 | 0.000 | 26 | 否 |
| 100 | 50 | 0.333 | 0.408 | 0.000 | 51 | 否 |
| 500 | 250 | 0.333 | 0.366 | 0.000 | 251 | 否 |
| 5000 | 2500 | 0.333 | 0.344 | 0.000 | 2501 | 否 |
| 12 | 8 | 0.455 | 0.778 | 0.333 | 5 | **是**（并集恒为全体） |
| 100 | 80 | 0.667 | 0.720 | 0.600 | 21 | **是** |

三条实现时必须遵守的结论：

1. **随机划分的 J₅₀ 恒在 1/3 附近**（大 N 下趋近 1/3），**与 N 几乎无关**；只有 J₉₅ 随 N 增大而收紧（N = 5000 时仅 0.344）。所以"J 很大"本身在随机划分下也常见，必须比的是**分位数**，不是绝对值。
2. **固定 0.90 阈值在两端都失效**：实测在 N = 12、k = 6 时 P(J ≥ 0.90) = 0.0011，在 N = 5000、k = 2500 时 P(J ≥ 0.90) ≈ 0（远小于 10⁻⁶）。**即 0.90 这条线实际上永远不触发，检查形同虚设。**（这条是采用零分布的直接实证依据）
3. **退化区间可精确定界**：当 2k > N 时并集恒等于全体 N 个实体，J 的取值被压缩（如 N = 12、k = 8 时 J 只能取 5 个值、最小 0.333），此时 CHECK-1 无法区分"划分变了"与"划分没变"→ 判 `degenerate`，转 §5。

实现完成后，用上表做**回归基准**：给定 (N, k) 算出的 J₅₀/J₉₅ 必须与表中数值一致（精确法应完全一致；蒙特卡洛在 M ≥ 10000 下允许 ±0.01 误差）。

## 5. 实体数不足时的替代路线（不是放水，是换方法）

当实体数太少、无法既分离实体又保留足够测试样本时，**不允许**把 `verified` 直接置 true，而应：

1. 报告实际依赖结构（哪些样本属于同一实体）；
2. 改用**分层/混合效应模型**或**按实体聚类的稳健标准误**来估计不确定性；
3. 在稿件 Limitations 里写明"重复并非完全独立"。

## 6. 退出码与产物

**总规则（R3 修订）**：**只要四项检查中有任意一项为 `not-run`，`verified` 就不得为 `true`**，只能为 `false`，并在 `notes.seed_independence.partial_scope` 里列出未跑的检查项。理由：早期版本允许"1、2 pass 且 3、4 not-run 就置 true"，等于把"没查"混同于"查过了"，正是这类自检最容易被形式化绕过的地方。

| 退出码 | 条件 | `verified` | 后果 |
|---|---|---|---|
| 0 | 四项全部 `pass` | 可置 `true` | 允许引用；稿件可用 "independent partitions" 类措辞 |
| 1 | 任一检查 `fail` | 必须 `false` | **结果不得被引用**；需重做划分或转 §5 替代路线 |
| 2 | 输入缺失/格式错误 | 必须 `false` | 无结论 |
| 3 | 无 `fail` 但有 `not-run` | 必须 `false` | 可引用**但措辞降级**（见 §8）；`partial_scope` 记录未跑项 |

报告写入 `runs/smoke/seed_independence_<seedset>.json`，字段除 `notes.seed_independence` 的必填项外，还应含：

- `checks`：逐项 `pass` / `fail` / `not-run` + 证据；
- `jaccard`：成对值 + 最小值/最大值/均值；
- `thresholds`：`N`、`k`、`null_jaccard{j50, j95, method, seed, M}`；
- `partial_scope`：未跑的检查项列表（无则为空数组）；
- `generated_at`。

smoke 产物按 `AGENTS.md` §2 **不得**进入任何对外文本——它的作用是决定 `verified` 能否置 true，不是作为结果引用。

## 7. 本自检**不做**什么（防止被当成结论使用）

1. 不运行任何实验，不产生性能数字；
2. 不证明统计显著性，也不替代功效分析；
3. **不因为"通过"就使结论升级**：独立性只是 A 级证据的必要条件之一，还缺对照、效应量与 CI；
4. 不检查"种子数够不够"，只检查"这些种子是否构成独立重复"。

## 8. 与稿件措辞的对应关系

| 自检结果 | 稿件中允许的措辞 |
|---|---|
| CHECK-1 `pass`（J ≤ J₅₀，划分随种子变化） | "across 5 independent data partitions" |
| CHECK-1 `warn`（J₅₀ < J ≤ J₉₅） | "across 5 data partitions drawn independently at random"（保守一档，并在 Limitations 注明划分相似度接近随机范围下界） |
| CHECK-1 `fail`（同划分、仅初始化不同） | **只能**写 "across 5 random initializations on a single data split"，**不得**使用 independent / repeated 等词 |
| CHECK-1 `degenerate`（2k > N） | 不得声称独立重复；按 §5 改用分层模型并声明依赖结构 |
| CHECK-2 `fail` | 不得提交（存在泄漏，结论无效） |
| 任一检查 `not-run` | 措辞降级为 "… under a checked-by-time-split protocol (entity-level independence not verified)"；`verified` 必须为 `false` |
| CHECK-4 `not-run` | 不得声称"OTF 提供前瞻信息"——这正是 R1 质疑的核心 |
