## 3. 关键路径（★ 串起来的那条）

```
W1 公式抽出 → W2 OTF 实现 → W4 与论文表对拍 →(分叉)
                                     ├─ CPU 线：W5–W8 SUMO 合成真值 → W9 独立性自检
                                     └─ GPU 线：W11 GPU 决策 → W12 CARLA → W14 CfC → W15 OTF-CfC
                                                                                      ↓
                                                              W17 A1 消融 → W20 长尾 → W22 图表 → W24 投稿
```

**两个外部门控**（不解决则后续顺延，且**不得**用替代物冒充）：

1. **W11 的 GPU 门控**：无 GPU → W12–W21 的 CARLA 与训练全部顺延；CPU 线（W1–W10）不受影响。
2. **数据门控**：实车数据不到 → A1 只能用 SUMO 合成流，证据等级为 **C**，措辞只能是"在 SUMO 合成交通流中"（`AGENTS.md` §2）。
