## 9.1 结论

| 项 | 判定 |
|---|---|
| 当前状态 | **MAJOR REWORK**（新增 2 条指标层发现） |
| 是否达到 T-IV 强贡献门槛 | **否（证据不足）** |

**三个最关键理由**

1. **PID 基线跑通了**（CARLA 启动 38 s，单局 60 s）：`cost = 73.10`、`RMSE = 8.01 m`、`accel_sq = 2828`、`jerk_peak = 1571.18`。
2. **新发现 P1-Q：`jerk_peak` 在全部 150 个臂-局里恒等于 1571.18**（150/150，唯一取值）。
   它在代价里贡献 **15.71**，即**预注册均值 30.76 的 51.1%**。因为两端相同，它在 Δcost 里**抵消**——
   但这意味着**代价函数实际上不惩罚 jerk 差异**，"舒适性"这一维在复合代价里**没有区分力**。
3. **新发现 P1-R：CfC 臂的跟车 RMSE 均值 83.5 m（65.1–98.5），而 PID 只有 8.0 m。**
   说明被检验的控制器**跟车精度很差**，而"复合代价"的绝对值由这个巨大的跟踪误差主导。
   ⇒ 论文比较的是"两种跟车都不太准的变体"，不是"两种好控制器"。

## 9.2 PID 基线冒烟（真实 CARLA）

| 项 | PID | CfC off 臂（5 局均值） |
|---|---|---|
| following RMSE | **8.01 m** | 84.53 m |
| accel² integral | **2828** | 313.8 |
| jerk peak | 1571.18 | 1571.18（常数） |
| 复合 cost | **73.10** | 30.48 |
| travelled | 348.2 m | — |

**解读**：PID 跟得**准得多**（RMSE 小 10 倍），但**加速度剧烈**（accel² 大 9 倍），所以复合代价反而高。
这正是"未调优 PID"的典型形态：目标速度阶跃 → 加速度尖峰。**它现在还不能当公平基线。**

**下一步（未做）**：给 PID 加**一阶滤波 + 加速度限幅**，再重跑；否则审稿人会说这是稻草人。

## 9.3 新发现 P1-Q：代价里的 jerk 项是常数

| 项 | 值 |
|---|---|
| 出现次数 | **150 / 150**（75 局 × 2 臂） |
| 唯一取值 | **1571.18 m/s³** |
| 对代价的贡献 | 0.5 × 1571.18 / 50 = **15.71** |
| 占预注册均值 30.76 | **51.1%** |
| 去掉后 | 15.05 |
| 其中 RMSE 项 | 8.35（均值 RMSE 83.5 / 10） |
| 其中 accel 项 | 6.66（均值 333.2 / 50） |

**后果（必须分清两件事）**：

| 影响 | 是否受影响 |
|---|---|
| Δcost 与 TOST（配对差） | **不受影响**——两端都是同一常数，做差抵消 |
| "复合代价"的绝对值含义 | **受影响**——30.76 里有一半是常数量，不能读作"驾驶质量" |
| "同时优化舒适性"这一说法 | **受影响**——jerk 维在代价里是常数，**没有区分作用** |

**可能原因（H 级，未验证）**：开局第一个控制步的加速度阶跃（0 → 峰值）在 `/dt` 下被放大成 1571，
而每一步的差商都小得多，所以 max 恒定落在同一处。

**修复选项（需作者定）**：
1. 计算 jerk 时**跳过前 1 s**（burn-in），只统计稳态段；
2. 保留现状，但在论文里**明确说明** jerk 项对两端相同、不参与区分，并把"comfort"从主张里移除；
3. 换用 `mean |jerk|` 而不是 `peak`。

> ⚠️ 注意：选项 1 或 3 会**改变 Δcost**（因为两端 jerk 不再相同），从而可能改变
> "2/4 等价"的结论——这不是文字修改，是**重新分析**，必须重跑统计并改写结论。

## 9.4 新发现 P1-R：被检验的控制器跟车精度很差

| 量 | 值（预注册 40 臂） |
|---|---|
| following RMSE 均值 | **83.5 m**（65.1–98.5） |
| 期望车距 | `d_des = 5 + 1.4·v`，30 m/s 时约 **47 m** |
| 实际 RMSE 与期望车距之比 | **≈1.8 倍** |

**含义**：控制器并没有把车距维持在期望值附近；RMSE 与期望车距同量级甚至更大，
说明**跟踪本身是失效的**。这直接影响论文的解读：
- "两种输入谁更好"比较的是**两个都很差的控制器**；
- 这也解释了为什么 Δcost 很小（都在做大误差，差异被淹没）；
- 与 PID 的 8 m 一比，差距是**十倍量级**。

**这不是造假，是外部效度问题**：审稿人一旦要求"跟车误差应在几米内"，全文的代价对比就失去意义。

**需要作者决定**：是（a）如实披露"控制器跟车误差较大，结论只在该工作点成立"，
还是（b）**降低期望车距/换更简单场景**重跑，还是（c）接受并在 Limitations 里写清。
