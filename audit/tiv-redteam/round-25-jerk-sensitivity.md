**最关键的三条**

1. **我在 Round 23 说"常数在 Δ 中抵消，所以不影响结论"——错在只看 Δ，没看 TOST 的 margin。**
   margin 定义为 **off 臂均值的 10%**；jerk 常数把 off 均值从 **14.77 抬到 30.48**，也就把 margin 从 **1.48 抬到 3.05**。
   **margin 被抬大一倍，等价就更容易被判成立。**
2. **扣掉常数后，2 个"等价"翻成"未定"**：

   | 场景 | 原 Δ / TOST p / 状态 | 扣常数后 | 变化 |
   |---|---|---|---|
   | none | +0.256 / 0.0198 / **equivalent** | +0.256 / 0.1293 / **inconclusive** | **翻转** |
   | cutin | +0.326 / 0.0273 / inconclusive | +0.326 / 0.1613 / inconclusive | 不变（未定） |
   | lead-brake | +0.858 / 0.0515 / inconclusive | +0.858 / 0.2824 / inconclusive | 不变（未定） |
   | lead-exit | −0.051 / 0.0060 / **equivalent** | −0.051 / 0.0527 / **inconclusive** | **翻转** |

   ⇒ **"两个场景等价"这一主要结论，依赖于一个指标常数**。
3. **而且每帧轨迹没有落盘**，所以 jerk **无法事后重算**：要么保留现口径（并承认结论对口径敏感），要么**重跑全部 40 局**。

## 9.2 为什么会翻转（机制）

| 量 | 含常数 | 扣常数 |
|---|---|---|
| off 臂均值 | 30.48 | **14.77** |
| TOST margin（10%） | **3.05** | **1.48** |
| none 的 95% CI | [−2.32, +2.83] | 同（Δ 不变） |
| CI 是否落在 ±margin 内 | **是** → 等价 | **否**（2.83 > 1.48）→ 未定 |

**要点**：Δ 与 CI **完全不受影响**（常数两端相同、做差抵消）；受影响的只有 **margin**。
而 margin 是"相对量"，它以一个**被伪迹抬高的均值**为基准，因此**系统性放宽**了等价判据。

## 9.3 这对论文意味着什么

| 论文主张 | 现状 |
|---|---|
| "Two of four scenarios are statistically equivalent within a 10% margin" | **成立，但只在该代价口径下**；换口径即消失 |
| "The margin was pre-registered" | 是的，但**预注册时没有人检查过代价里含 51% 的常数量** |
| "Composite driving cost 30.5" | 其中 15.71 是常数伪迹，**不能读作驾驶质量** |

**这不是造假，是"预注册的口径本身含缺陷"**：预注册保护了"不事后调参"，但没有保护"口径的物理含义正确"。
