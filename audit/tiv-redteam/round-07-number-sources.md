## 9.3 严重问题（本轮）

### P1-M（新，重大）：Fig.2 的统计量未定义且与另两个来源不一致

- **现象**：CARLA 点 = **跨场景共享值/最小值**；TGSIM 点 = 10 个 run 的**均值**；SUMO 点 = 3 个种子 × 密度的**均值**。
- **后果**：摘要的"约 1/6"依赖这个不对称（0.532/0.084 = 6.3；若用合并均值 0.532/0.0965 = 5.5；若用 lead-exit 上界更小）。
- **为什么重要**：这是 C1（跨来源可用性）的**核心数字**；口径不对称是最容易被审稿人抓的地方，且它同时放大了本文的叙事。
- **修复动作（三选一，需作者定）**：
  1. **改图为合并均值 + 误差范围**，正文与摘要同步改成 0.096（0.084–0.168）；
  2. **保留最小值**，但在图注与正文**显式定义**："plotted value is the fraction shared by the three scenarios without lead-exit crossings"，并把 TGSIM/SUMO 也改成同口径（例如取最小 run 而非均值）；
  3. 两者都报：主点用合并均值，最小值作为下限标注。
- **验收标准**：Fig.2 三个来源的统计量在图注中各有一句定义；摘要数字与该定义一致；`audit_number_sources.py` 无 WARN。
